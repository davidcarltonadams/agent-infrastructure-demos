Agent Infrastructure — Interactive Demos

Synthetic demos of a personal multi-agent system by David Carlton Adams. All data is fictional; the architecture and interaction are real.

Flightpath — one-true-state project layer: cards, milestone bars, dependencies, collapse at every level.
The Gazette — a daily personal newspaper: ranked classifieds, puzzle corner, graded course lesson.
Gander — timeline + what-if sandbox over the same state layer: derived schedules, dependency cascades. Drag a bar and downstream dates follow; copy the scenario out as a proposal.

Self-contained HTML, no external requests. See the README for the architecture notes.
